### ShikshaSaathi AI

**ShikshaSaathi AI** is an AI-powered learning assistant designed to help teachers identify and address different learning levels within the same classroom.

In many low-resource classrooms, a single teacher manages students with very different abilities in reading, comprehension, and basic mathematics. This makes individual assessment and personalized teaching difficult.

ShikshaSaathi AI uses **AI-powered assessments** to understand each student's current learning level, identify learning gaps, and generate personalized learning activities. It also provides teachers with an **AI-powered classroom dashboard** that highlights students who need additional support and recommends actionable interventions.

The platform aims to transform classroom data into meaningful action—helping teachers teach more effectively while ensuring that **every child learns at their own level and pace**.

**Core Features:**
- 🤖 AI-based learning-level assessment
- 📚 Personalized learning activities
- 👥 Automatic student learning groups
- 📊 Teacher classroom dashboard
- 🎯 Learning-gap identification
- 🗣️ Voice and multilingual support
- 📈 Student progress tracking

**Tagline:**  
*“Every Child at Their Level. Every Teacher with AI.”*
